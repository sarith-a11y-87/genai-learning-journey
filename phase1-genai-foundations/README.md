# Phase 1: Generative AI foundations (6 Dec – 25 Dec 2026)

Starts only after the Phase 0 foundation gate is passed. A detailed day-by-day plan is added when the phase begins.

**Topics:** how LLMs work (tokens, embeddings, transformers and attention, context windows,
temperature and sampling). Calling Claude, OpenAI and Gemini APIs: streaming, structured output,
token costs. Prompt engineering: system prompts, few-shot examples, output schemas. Open models with Ollama.

**Certificate:** Databricks Generative AI Fundamentals.

**Gate:** a CLI chatbot with memory, streaming and a token-cost counter. Start it by extending
`../phase0-python-for-ai/gate-chat-api`.
