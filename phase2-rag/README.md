# Phase 2: RAG (2 Jan – 29 Jan 2027)

**Topics:** chunking, embeddings, vector search with pgvector on Supabase, retrieval with cited
answers, hybrid search (BM25 plus vectors), reranking, metadata filters, evaluation with RAGAS and a
golden test set. Then advanced patterns: agentic RAG, GraphRAG and multimodal RAG.

**Gate:** Project 1, the **Private Wealth Document Assistant**, with an evaluation report.
Use synthetic documents only. Never commit real client data.
